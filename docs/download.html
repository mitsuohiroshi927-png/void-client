How to install

  1. Click Download above.
  2. Open https://github.com/mitsuohiroshi927-png/void-client/releases/download/v1.2.5/VOID-Client-1.2.5-Setup.exe.
  3. If Windows warns you → More info → Run anyway.
  4. Click Next through the installer, then open VOID Client from the Start Menu.
  5. Pick a Minecraft version, make a profile, press PLAY. Java 21 is handled for you.

What you get

  • Every Minecraft 1.21.x version, with Fabric Loader ready to go
  • VOID Client bundled in — the performance boost without manual mod installs
  • Mods install from Modrinth inside the launcher, isolated per profile
  • Resolution on Auto (follows your hardware) or Custom, your choice
  • Java 21 downloaded and checksum-verified, RAM tuned to your hardware
  • Discord Rich Presence, community stats, toast notifications
