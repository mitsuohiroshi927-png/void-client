⚠ Windows akan menampilkan peringatan

Saat menjalankan installer, Windows mungkin menampilkan “Windows protected your PC” atau “unknown publisher”. Ini karena installer-nya belum punya sertifikat digital berbayar — bukan karena ada virus.

Cara mengatasinya: klik More info, lalu Run anyway.

Kalau kamu ragu, kode sumbernya bisa dibaca bebas di repository GitHub — jadi kamu bisa lihat sendiri apa yang dijalankan sebelum kamu pasang.

Cara install

  1. Klik tombol Download di atas.
  2. Buka file https://github.com/mitsuohiroshi927-png/void-client/releases/download/v1.2.5/VOID-Client-1.2.5-Setup.exe.
  3. Kalau muncul peringatan Windows → More info → Run anyway.
  4. Klik Next sampai selesai, lalu buka VOID Client dari Start Menu.
  5. Pilih versi Minecraft, buat profil, tekan PLAY. Java 21 diurus otomatis.
