Why VOID

Made so you can play, not configure

Most launchers make you install Java, pick a loader, and hunt for mod files before you ever see the title screen. This one does all of that for you.

The boost ships with it

VOID Client is bundled inside the launcher and loaded on every profile — no benchmark mods to hunt down, no loader guessing.

Crosshair Studio

Design your crosshair on a live preview: four shapes, size, gap, thickness, seven colours, and a highlight colour for when a target is under it.

Light on your PC

No heavy framework in the launcher, and the in-game menu animates on a frame-time budget — switch the motion off and it costs nothing.

Mods from inside

Search and install from Modrinth without leaving the app. Every profile keeps its own mods — nothing leaks between them.

Profiles that stay apart

Own mods, RAM, resolution, Minecraft version and loader per profile. Create one and it starts clean, not as a copy of the last.

Accounts, done properly

Everything account-related lives in the chip at the top right: the real player head, several accounts saved side by side, and a browser code login.

What's new

Fresh in Version 1.3.9

The launcher and the in-game client now carry the same version number, and this release is mostly about the things you actually look at while playing.

Crosshair Studio

A screen of its own with a crosshair drawn five times bigger, so gap and thickness are readable. Four shapes, colour swatches, a centre dot, and a target-highlight preview. The custom crosshair now really replaces the vanilla one, and size/gap/thickness finally apply to every shape.

Menu in dark gray and blue

Neutral gray surfaces with blue as the default accent (cyan, purple, pink and green stay available). Motion is driven by real frame time, so it looks the same on 30 fps and 240 fps — and one switch turns it off.

In-game profiles fixed

A new profile slot is built from the defaults instead of inheriting whatever you were running, and a saved slot no longer disappears the moment it is applied.

The bundled mod actually loads

The launcher decided which Minecraft versions the bundled mod supports from a stale table, so it was silently never attached. It now reads that range from the mod itself, honours each profile's own version and loader, and says so in the log when it skips.

Account up top, heads included

The separate Account page is gone. The chip in the top right shows the player's real head, keeps several accounts and switches between them — and the hair-on-fire detail: Mojang hands out http skin URLs, which Chromium refuses on a local page, so the head is cropped in the launcher process instead.

Updates install themselves

VOID Client checks on start, downloads in the background, verifies the SHA-256 and installs when the game is closed — no clicks. Both Windows and Linux builds are published, and the Linux button really does serve the AppImage.

Questions

The things everyone asks

Answered here so you don't have to go looking.

Windows says "Windows protected your PC" — is it a virus?

No. Windows shows that warning for any installer without a paid digital certificate. Certificates cost a few hundred dollars a year, and this project doesn't have one yet. Click More info, then Run anyway. You can also verify the file yourself with the checksum further down this page.

Do I need a Minecraft account?

Yes. VOID Client is a launcher, not a copy of the game. You need to own Minecraft on a Microsoft account to play, exactly like the official launcher.

Will it run on my PC?

If you're on 64-bit Windows 10 or 11 with at least 4 GB of RAM and a graphics card that supports OpenGL 3.2, yes. Anything older than that won't work — those are real limits, not marketing.

Is it safe? What does it do with my account?

The full source code is public on GitHub, so anyone can read it. Login uses Microsoft's own device-code flow: you type a code on Microsoft's website, and your password never touches the launcher. The launcher only downloads official game files and mods from public sources.

How do updates work?

Settings has a Check for updates button. When a new version exists it shows you the old version, the new version, and what changed — then installs it. Updates download from this website, with GitHub as an automatic backup if this server is ever down.

Is VOID Client affiliated with Mojang or Microsoft?

No. It's an independent project. It requires a legitimate Minecraft account and only downloads official game files.
