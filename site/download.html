How to install

Windows

  1. Click Download above.
  2. Open VOIDClient-Setup.exe.
  3. If Windows warns you → More info → Run anyway.
  4. Click Next through the installer, then open VOID Client from the Start Menu.
  5. Pick a Minecraft version, make a profile, press PLAY. Java 21 is handled for you.

Linux — one file, nothing to install:

  1. chmod +x VOID-Client-1.4.1-x86_64.AppImage
  2. ./VOID-Client-1.4.1-x86_64.AppImage — or double-click it in your file manager.
  3. No FUSE on your system? Use the .tar.gz build from the same release page instead.
  4. Pick a Minecraft version, make a profile, press PLAY. Java 21 is handled for you.
