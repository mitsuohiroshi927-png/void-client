39 mod · semua client-side · MC 1.21.x

Isi boost pack-nya.

Ini daftar lengkap mod yang dipasang launcher saat kamu centang paket Performance di tab Mods. Semuanya dari Modrinth, semuanya sisi klien — tidak ada yang perlu dipasang di server. Klik nama mod untuk buka halaman Modrinth-nya.

📦 Lihat profil Modrinth aku ← Kembali ke beranda
FPS19
  • sodiumRewrites the chunk renderer: the single biggest FPS gain.
  • cull-leavesLeaves render only the faces you can actually see.
  • morecullingCulls block faces hidden by other blocks.
  • entitycullingSkips rendering entities that are behind walls.
  • particlecullingHides particles you cannot see.
  • particle-coreMakes particle rendering cheaper.
  • greedy-meshingMerges adjacent block faces into one quad.
  • obeOptimised block entities (chests, signs, banners).
  • scalableluxMultithreads light updates (ex-Sodium light engine).
  • badoptimizationsRemoves CPU work per frame that nothing needs.
  • clumpsMerges clumps of XP orbs into a single entity.
  • dynamic-fpsDrops the frame rate while the window is in the background.
  • better-render-distanceMakes render distance spherical, so fewer chunks render for the same reach.
  • entity-view-distancePer-entity view distance: distant mobs stop costing frames.
  • fastchest-revivedDraws chests as normal blocks instead of block entities.
  • ebe-reloadedBatches block entities (chests, signs, beds) into fewer draw calls.
  • fps-reducerDrops GPU/CPU use while you are idle or tabbed out (FPS Reducer).
  • sodiumfpscapfixRemoves the 260 FPS ceiling and adds a real FPS cap box.
  • immediatelyfastRewrites immediate-mode rendering: fastest wins on text, items and HUD-heavy screens.
Visual1
  • clear-fogRemoves fog, which also drops a draw pass.
CPU3
  • lithiumOptimises the game logic itself: physics, AI, ticking.
  • consumableoptimizerHandles eating/drinking client-side instead of waiting on the server.
  • asyncloggerLogging moves off the main thread, so log writes stop hitching frames.
Memory2
  • ferrite-coreCuts block/item model memory by up to a third.
  • jasioneCuts GC pressure by removing throwaway enum array copies.
Network2
  • kryptonFaster, lighter networking stack.
  • fast-ip-pingResolves server addresses faster.
Chunks2
  • c2me-fabricLoads chunks on multiple threads.
  • moonrise-optFaster integrated-server worldgen: bigger win the further you explore.
Server-side6
  • fastserverpingsRewrites the server-list ping so the multiplayer menu fills instantly.
  • serverpingerfixerFixes the ping shown for servers whose icon fails to load.
  • serverlist-fixLifts the thread cap that makes large server lists stall.
  • serveraddressspacefixFixes "unknown host" when adding an address with spaces or a port.
  • resourcepackcachedKeeps the server resource pack on disk so re-joining does not re-download it.
  • server-resource-pack-checkerOnly applies a server pack when it actually changed — no reload stall.
Fixes1
  • debugifyFixes dozens of vanilla bugs, including several lag causes.
Crosshair2
  • custom-crosshair-modCustom crosshair shape, colour and size.
  • dynamiccrosshairCrosshair reacts to what you are targeting.
Wajib1
  • fabric-apiThe Fabric API most mods are built against.
Catatan. Mod yang tidak punya rilis untuk versi Minecraft yang kamu pilih akan dilewati, bukan dipaksa dipasang — itu cara paling aman supaya profil tidak gagal boot. Paket ini juga bukan syarat: kalau satu unduhan gagal, sisanya tetap terpasang dan Minecraft tetap bisa dibuka.
